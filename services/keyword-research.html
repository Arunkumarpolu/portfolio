Scope and practical guidance

How Keyword Research work is scoped

Keyword research should lead to a decision about which page should answer a search, rather than stop at a spreadsheet of search volumes. I combine the business's services and audience with query patterns, existing URLs, Search Console data where available and the page types appearing in search results.

Close variants can belong in one cluster when they share an intent. Different intents may need separate pages. Mapping keywords to existing URLs helps reveal overlap: two pages targeting the same need may need clearer roles, consolidation or stronger internal links. Estimated volume is a comparison signal, not a forecast of traffic.

A useful map records the query group, intent, target URL, page type, primary and supporting topics, priority rationale and any subject-matter questions. It also notes when no new page is needed because an existing URL already serves the search. This reduces accidental duplication as the content plan grows.

Prioritization should reflect business fit as well as estimated demand. A smaller, relevant query can be more useful than a broad term that attracts the wrong audience. Record assumptions, data sources and review dates so the team can revisit the map when products, locations or search behavior change.

FAQs

Frequently Asked Questions About Keyword Research

What do you need to start keyword research?

A description of the business, audience, products or services, target markets and goals. Existing URLs and Search Console exports are useful but optional.

Are search-volume estimates exact?

No. Estimates help compare relative demand, but intent, relevance, competition and business value should also guide priorities.

How do you spot keyword cannibalization?

Compare query intent with existing pages and assign each cluster a clear primary URL; recommendations may differentiate, consolidate or link pages.

Does every keyword need its own page?

No. Closely related searches with the same intent can often be served by one useful page.
